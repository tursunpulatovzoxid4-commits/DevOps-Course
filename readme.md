## ✨ Asosiy xususiyatlar
- ⚡ **Tezkor va yengil:** Ishlash tezligi yuqori darajada optimallashtirilgan.
- 📱 **Responsive dizayn:** Har qanday ekran o'lchamiga moslashadi (mobil, planshet, kompyuter).
- 🔒 **Xavfsiz:** Zamonaviy xavfsizlik standartlariga javob beradi.

## 🛠 Texnologiyalar
Ushbu loyihani yaratishda quyidagi texnologiyalar va kutubxonalardan foydalanildi:
* **Frontend:** [React](https://react.dev/) / [Vue.js](https://vuejs.org/) / HTML5, CSS3
* **Backend:** [Node.js](https://nodejs.org/), [Express](https://expressjs.com/)
* **Ma'lumotlar bazasi:** [MongoDB](https://www.mongodb.com/) / [PostgreSQL](https://www.postgresql.org/)
